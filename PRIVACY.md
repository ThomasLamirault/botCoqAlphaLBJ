# PRIVACY.md
## Politique de Confidentialité du bot LBJ
Dernière mise à jour : septembre 2026
Votre vie privée est importante. Cette politique explique comment le bot "LBJ" gère vos données lorsque vous l'utilisez sur Discord.

### 1. Collecte des informations
Le bot recueille uniquement les données strictement nécessaires à son fonctionnement technique, notamment via l'API de Discord :
- **Identifiants (IDs)** : L'ID de votre compte utilisateur et celui du serveur où le bot est présent (nécessaire pour identifier qui a lancé une commande).
- **Contenu des messages** : Le texte que vous envoyez au bot est analysé uniquement en temps réel pour générer une réponse. Il n'est pas stocké dans une base de données persistante après la fin du traitement, sauf si cette fonctionnalité spécifique l'exige explicitement et avec votre consentement.

### 2. Utilisation des informations
Les données recueillies sont utilisées exclusivement pour :
- Exécuter les commandes que vous lui donnez.
- Assurer le bon fonctionnement et la maintenance du bot (journalisation d'erreurs techniques).
- Le bot ne vend jamais vos données à des tiers ni ne les utilise pour du profilage publicitaire.

### 3. Sécurisation
Les données sont traitées sur des serveurs sécurisés. Bien que nous fassions de notre mieux pour protéger vos informations, aucune transmission par internet ou méthode cryptographique n'est garantie à 100 %.

### 4. Droits des utilisateurs
Conformément au RGPD et aux lois applicables, vous avez le droit d'accéder, de corriger ou de demander la suppression de vos données personnelles en contactant les  administrateurs du bot via Discord.
